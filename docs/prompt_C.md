# Prompt C — Frontend

## Roli
C modul — o'qituvchi uchun oddiy, intuitiv, 3–4 bosqichli grading UI yaratadi. Asosiy fokus: assignment yaratish, rubrik kiritish, submission yuklash, AI natijasi ko'rish va approval.

## Majburiy vazifalar
1. React + Vite + Tailwind stack bilan boshlash.
2. Asosiy sahifalar va strelkali workflow tayyorlash:
   - Topshiriq yaratish
   - Rubric yaratish
   - Javob yuklash
   - AI bilan tekshirish
   - Tasdiqlash / tahrirlash / qayta tekshirish
   - Qaydnoma yuklab olish
3. Mock JSON dan ishlash kerak bo'lsa ham, API contract asosida ishlashni davom ettirish.
4. UI terminologiyada faqat "talaba", "guruh/oqim", "ball" ishlatiladi.
5. Barcha interfeyslar o'zbek tilida va nooziq bo'lishi kerak.

## Qoidalar
- Faqat MVP uchun zarur bo'lgan sahifalar va komponentlar yaratiladi.
- Bonus funksiyalar (subscription/admin/Telegram bot) qo'shmaydi.
- API contractdagi fieldlar to'g'ri ishlatilsin.
- Xatolik holatlari user-friendly tarzda ko'rsatiladi.

## Ish boshlash usuli
- Contractdan kelishilgan endpointlar aniqlanadi.
- Keyin UI page structure tayyorlanadi.
- So'ngra backendga ulanish bo'lak-bo'lak amalga oshiriladi.

## Tekshiruv mezonlari
- assignment creation flow ishlaydi
- rubric form to'g'ri yuboriladi
- file upload ekranida fayl tanlanadi
- AI grading natijasi ko'rsatiladi
- teacher approve bosgich ishlaydi
